# Screen Time Analysis Using Python

## Project Overview
This project analyzes smartphone screen time and app usage patterns using Python. It uses a dataset containing 2,000 synthetic screen-time records representing users from different cities and states in India.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Features
- Personal information: Age, Gender, City, State, Occupation
- App information: App, Usage, Notifications, Times opened
- Device information: Phone OS, Internet Type
- Lifestyle information: Sleep Hours, Study/Work Hours
- Other details: Phone Unlocks, Data Usage

## Data Analysis
- Dataset exploration
- Missing value and duplicate checking
- Statistical analysis
- App-wise usage analysis
- Age-wise and city-wise analysis
- Correlation analysis

## Visualizations
1. App-wise Screen Time Bar Chart
2. Daily Screen Time Trend
3. Screen Time Distribution Histogram
4. Notifications vs Screen Time Scatter Plot
5. Correlation Heatmap

## How to Run

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Open the notebook:

```bash
jupyter notebook Mini_project.ipynb
```

Run all cells to perform data cleaning, analysis and visualization.

## Dataset Note
The dataset contains synthetic data generated for educational and analytical purposes. It does not represent actual survey results from real individuals.
